# Hotel Management System

The Hotel Management System is a web application designed to support hotel operations management.

## Key Features

- Room and room type management
- Room reservations and deposit payments
- Check-in, check-out, and invoicing
- Service, housekeeping, and maintenance management
- Role-based account management
- Reporting and statistics

## Technologies

- Java Servlet/JSP
- SQL Server
- Maven
- MoMo Payment Gateway
